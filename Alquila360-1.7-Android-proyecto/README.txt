Alquila360 1.2 beta — Android

Novedades:
- Importar y exportar copias con el selector nativo de archivos Android (SAF).
- Filtros por año y mes en Cobros y Gastos.
- Recibo integrado con botón Volver y diálogo nativo de impresión / Guardar como PDF.
- Icono Android propio y nueva apariencia.
- Botón Atrás físico vuelve de recibo a Cobros o de sección a Resumen.

Compilación GitHub Actions: Gradle 8.9, Java 17, SDK 35.
El workflow debe apuntar a Alquila360-1.2-Android-proyecto.

ATENCIÓN: versión beta no validada en dispositivo real. Exporta copia de seguridad antes de actualizar.
Las compilaciones debug de GitHub pueden firmarse con claves diferentes; no desinstales la versión anterior hasta verificar la copia de seguridad.
La aplicación sigue usando localStorage dentro de WebView, sin sincronización.
